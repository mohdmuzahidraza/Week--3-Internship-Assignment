# Week 3 Internship Assignment – Java OOP

## 📖 Overview

This repository contains Java assignments and a mini project completed as part of the Week 3 Internship Assignment. The projects demonstrate core Object-Oriented Programming (OOP) concepts including Classes, Objects, Inheritance, Abstraction, Encapsulation, and Polymorphism.

---

## 📂 Projects

# 1️⃣ Student Class Implementation

Description
A Java program that creates a Student class with attributes and methods to display student information.

#Concepts Covered
- Classes and Objects
- Constructors
- Methods

Sample Output

```
Name: Muzahid
Roll No: 101
Course: B.Tech
```

---

# 2️⃣ Vehicle Inheritance Example

Description
A Java program demonstrating inheritance and method overriding using a Vehicle base class and Car and Bike subclasses.

Concepts Covered
- Inheritance
- Method Overriding
- Polymorphism

Sample Output

```
Car starts with a key.
Bike starts with a self-start button.
```

---

# 3️⃣ Library Management System

Description
A mini project that simulates a basic Library Management System using Object-Oriented Programming concepts.

Features
- Add Books
- Borrow Books
- Return Books
- Track Book Availability

OOP Concepts Used

- Encapsulation
- Inheritance
- Abstraction
- Polymorphism

Classes Used

- Book
- Library
- User
- Stud

Sample Output

```
Book Added: Java Programming
Book Added: Data Structures
Muzahid is a Student.
Book Borrowed: Java Programming
Book Returned: Java Programming
```

Compile

```bash
javac StudentClassImplementation.java
javac VehicleInheritance.java
```

```bash
java StudentClassImplementation

```
